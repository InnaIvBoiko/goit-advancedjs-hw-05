# goit-advancedjs-hw-05

Homework. Introduction to TypeScript — setting up and configuring a TypeScript
development environment with source maps for in-browser debugging.

## Overview

A small TypeScript project that compiles `src/*.ts` into `dist/*.js` and runs in
the browser through a local dev server. Clicking the **Concat!** button
concatenates the input value with `"hello!"` and logs the result to the console.

## Tech stack

- [TypeScript](https://www.typescriptlang.org/)
- [@web/dev-server](https://modern-web.dev/docs/dev-server/overview/)
- Node.js / npm

## Project structure

```
.
├── index.html          # Entry page, loads dist/index.js as a module
├── tsconfig.json       # Compiler configuration
├── src/                # TypeScript sources
│   ├── index.ts
│   └── concatenation.ts
└── dist/               # Compiled JS + source maps (generated by tsc)
```

## Getting started

Install dependencies:

```bash
npm install
```

Compile the TypeScript sources:

```bash
npx tsc
```

Or watch for changes and recompile automatically:

```bash
npx tsc -w
```

Start the dev server (opens the app in the browser):

```bash
npm start
```

## Debugging with source maps

`sourceMap` is enabled in [tsconfig.json](tsconfig.json), so `tsc` emits a
`.map` file next to every compiled `.js` file. This lets the browser map the
running JavaScript back to the original TypeScript: open the **Sources** tab in
DevTools, set a breakpoint directly in a `.ts` file, and step through the code
as if TypeScript were executing.
